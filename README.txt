RANDOMIZER 3D — PINK CLOUDS

Запуск:
1. Распакуйте ZIP.
2. Откройте index.html в браузере (Safari, Chrome, Edge).
3. Вставьте список участников по одному имени на строку.
4. Нажмите «Добавить участников», выберите число победителей и крутите колесо.

Возможности:
- До 200 участников
- От 1 до 10 победителей
- Победители не повторяются в рамках одного розыгрыша
- Анимированное колесо, розовый облачный дизайн
- Работает локально в браузере, без установки и сервера
